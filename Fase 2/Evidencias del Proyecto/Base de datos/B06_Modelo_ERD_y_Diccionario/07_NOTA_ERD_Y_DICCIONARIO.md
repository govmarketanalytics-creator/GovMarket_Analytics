# ERD / diccionario de datos

El gráfico incluido corresponde a un ERD previamente aportado por el equipo. **No se ha verificado contra el esquema PostgreSQL vigente del 27-11-2026.**

La carpeta contiene también una entidad TypeORM real como evidencia de implementación.
Para completar la entrega final se necesita:

1. Exportar un ERD actualizado desde pgAdmin.
2. Exportar esquema con `pg_dump --schema-only` y contrastar tablas y restricciones.
3. Crear diccionario de columnas y relaciones a partir de resultados de `information_schema`.
4. Incorporar las imágenes reales de la aplicación en funcionamiento.

No debe afirmarse que el gráfico muestra exactamente la instancia de producción.
